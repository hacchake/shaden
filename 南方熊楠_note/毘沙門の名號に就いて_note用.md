# 【現代語訳】南方熊楠「毘沙門の名號に就いて」

毘沙門天には「クベラ」という別名がある――。帝釈天が毘沙門を「クベラよ」と呼びかけた仏典の一節を手がかりに、二つの名の使い分けを考え、毘沙門の名の由来の伝承や、金毘羅を鰐の神とみる説にも触れた熊楠の短い考証を全訳しました。

## クベラと毘沙門

　クベラ、またクピラが毘沙門天の異名であることは、『仏教大辞彙』巻一の倶肥羅天の条にすでに述べてある。

　私（熊楠）が言うに、この二つの名が一柱の神を指すことを立証するのに最もよい文句は、梁朝に勅命で編纂された『経律異相』巻四十一に『羅閲城人民請仏経』から引いたものだ。仏が鶏頭婆羅門の供養を許したとき、釈提桓因（帝釈）が毘沙門天王に語って言った。拘鞸羅（クベラ）よ、おまえはこの婆羅門のために三度目の食事を用意せよ、と。答えて言った。教えを承ります、とある。クベラは実名、毘沙門は通称のように見える。アイテルの『梵漢辞彙』一九三頁には、この神は前世で夜叉だったが、仏に帰依して沙門となった功徳によって、北方の神王に生まれ変わった。その沙門となったとき、ほかの沙門たちが驚いて「伊は是れ沙門（あの者も沙門か）」と叫んだ。それで毘沙門（ヴァイスラマナ、この男も沙門かの意味）の称を得た、とあるが、これは何の経に出ていることか、識者の高教を待つ。「伊は是れ沙門」は音と意味の両方の訳らしい。金毘羅（蛟の神）は、『大灌頂神呪経』巻七などを見ると、毘沙門とは別の神らしい。インドで古来鰐を拝むその鰐の神だろう。わが国で金毘羅を航路の神とするのも、この因縁か。仏弟子に金毘羅比丘がいて、独り住んで専念することを称えられた（『増一阿含経』巻三）。これも鰐を奉じた氏子だろう。（大正一五、三、集古、丙寅ノ二）
