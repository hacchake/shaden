# 【現代語訳】南方熊楠「棄老伝説について」

信州の姨捨山だけでなく、伊豆にも老人を棄てた伝説がある――。ヨーロッパ人の祖先にも同じ風俗があったことや、飛騨の「人落し」の言い伝え、親を棄てに行った子の気づきで棄老がやんだという東西に広まった話に触れた、南方熊楠の短文を現代語に訳しました。

## 老人を棄てる風俗

　誰もが知っている信州の姨捨山〔おばすてやま〕の話のほかに、伊豆にも棄老伝説があるというのは（『郷土研究』三の二四三）、棄てられた老人には気の毒だが、歴史書に見えない古い風俗を研究する人々には有益である。一九〇八年版ゴムの『歴史としての民俗学』第一章などを見ると、今日開明を誇るヨーロッパ人の多くの祖先も、都々逸の文句どおりに、年寄りは棄てられ若者が残るという風俗で平然としていたらしい。わが国はもとより比類のない神国で、上代の民が純朴だったことはわかりきったことだが、時代と範囲に応じて、今日から見ると奇怪な習慣もずいぶん行われたことは、大化の初年まで、人が死ぬと人を絞め殺して殉死させ、信濃国では夫が死ぬと妻を殉死させたことなどでわかる。

## 飛騨の人落しと、棄老がやんだ話

　だから地方によっては、老人を棄てる風習もあったのだろう。昨年、押上中将から贈られた『高原旧事』に、「飛騨の吉野村の下に人落しという所がある。昔は六十二歳になった者に限って、ここへ棄てたという」とある。さて、親を棄てに行った子が、自分もその年齢になれば棄てられると思いついたのがきっかけで、このことがやんだというのは、漢の皇甫謐の『孝子伝』、『万葉集』、『今昔物語』、グリムのドイツ童話その他に多く見えて、ヨーロッパ・アジアの諸国に広まった話である。（南方熊楠）
