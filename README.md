# 社伝 — 神社の由緒を集めて構造化する

日本の神社の**社伝（由緒）**を、複数の系統から機械的に集めて構造化し、
地図と一覧で読めるようにしたもの。

もとは饒速日命（にぎはやひのみこと）をめぐる社伝が
『先代旧事本紀』『日本書紀』『新撰姓氏録』にどれだけ依拠しているかを
測るための研究だったが、その過程で作った道具が全国規模に広がった。

## 見る

**[トップページ](https://hacchake.github.io/shaden/)**

**[社伝マップ](https://hacchake.github.io/shaden/map.html)** — 地理院タイルの実際の地図に
70,204 社を重ねたもの。地名を見ながら探せる。

**[社伝点描図](tenbyo.html)** — 全国 70,393 社を、地図画像を使わず座標の点だけで描いた図。
社の分布そのものから国土の輪郭が現れる。点を押すと祭神・例祭・社伝が出る。

## 饒速日研究（もとの目的）

依存推定では、対照群（底本の文字をランダムに並べ替えたもの）が
一致率 0.00% を返すことを確認したうえで測っている。

## 確度について

地誌からの引き当ては二段に分けている。

- **A** — 社名に加え郡・町村・大字まで一致（6,221 件）
- **B** — 社名と項目見出しの位置のみ一致（17,386 件）。**同名の別社である可能性がある**

B は地図上でも点線・「?」付きで区別し、断定していない。
いずれも NDL の原本コマへのリンクを必ず添えてあるので、原文で確認できる。

## データについて

この repository には**構造化した結果と書誌情報のみ**を置いている。
NDL の OCR 本文、各サイトから取得した本文の全文は含めていない
（利用条件の確認が必要なため）。手元で再現するには各道具を順に走らせる。

Wikipedia 由来の本文（`data/wiki/`）は CC BY-SA 4.0。

## 取得の作法

- robots.txt を確認し、全面拒否のサイトは対象から外している
- User-Agent に用途と連絡先を明記
- 要求間隔は 0.8〜1 秒
- Google マップの自動巡回はしない（利用規約が禁じているため、由緒板は人が集めた URL を渡す半自動運用）
